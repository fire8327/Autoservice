# Autoservice

Модульная платформа шаблонов и лендингов для автокомплексов, станций технического обслуживания и детейлинг-центров.

## Структура репозитория

```text
Autoservice/
└── MT/                           # Автокомплекс «МТ» (г. Канаш, ул. Кооперативная, 43)
    ├── data/
    │   └── service-data.json     # 100% данных изолировано в JSON (контакты, цены, ТО)
    ├── images/
    │   ├── logo.jpg              # Официальный логотип
    │   └── cover.jpg             # Фото боксов сервиса
    ├── css/
    │   └── style.css             # Немецкий премиум-монохром + динамические анимации
    ├── js/
    │   ├── engine.js             # Data-driven гидратация DOM и анимации
    │   └── mileage-radar.js      # Интерактивный Радар ТО по пробегу с одометром
    ├── index.html                # Семантический каркас лендинга
    └── server.js                 # Легковесный статический сервер Node.js
```

## Быстрый старт

```bash
cd MT
node server.js
```
Сервер запустится по адресу: `http://localhost:3002/`
