# Autoservice

Модульная платформа шаблонов и лендингов для автокомплексов, станций технического обслуживания и детейлинг-центров.

## Структура репозитория

```text
Autoservice/
├── MT/                           # Автокомплекс «МТ» (г. Канаш, ул. Кооперативная, 43)
│   ├── data/service-data.json    # Данные бренда (Рейтинг 5.0, запчасти, ТО)
│   ├── images/                   # Медиа и логотип
│   ├── css/style.css             # Премиум-монохром + кинематика
│   ├── js/                       # Движок гидратации и Радар ТО
│   ├── index.html                # Каркас шаблона
│   └── server.js                 # Порт 3002
│
└── Chkalova/                     # Автокомплекс на Чкалова (г. Канаш, ул. Чкалова, 2)
    ├── data/service-data.json    # Данные бренда (Рейтинг 4.7, 3D сход-развал, АКПП, ДВС)
    ├── images/                   # Официальный логотип и обложка бокса
    ├── css/style.css             # Стили и анимации
    ├── js/                       # Движок и калькулятор ТО
    ├── index.html                # Каркас шаблона
    └── server.js                 # Порт 3003
```

## Быстрый запуск любого сервиса

### МТ Автокомплекс (Кооперативная, 43):
```bash
cd MT
node server.js
# Доступен на http://localhost:3002/
```

### Автокомплекс на Чкалова (Чкалова, 2):
```bash
cd Chkalova
node server.js
# Доступен на http://localhost:3003/
```
